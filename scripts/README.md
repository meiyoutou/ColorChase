# 脚本说明

## 目录结构

- `migrations/active/` — 待执行的迁移/修复脚本
- `migrations/archived/` — 已执行完毕的迁移脚本归档
- `tools/` — 可重复使用的开发/发布工具
- `setup/` — 首次部署环境时运行的初始化脚本
- `services/` — 需要长期运行的后台服务

## 使用原则

1. 执行任何迁移前必须备份数据库和 `storage/` 目录。
2. 生产环境执行迁移需要两人确认。
3. 迁移执行后必须记录到 `migrations/archived/EXECUTED.md`。
4. 归档迁移保留作为审计记录，超过 30 天可转存到离线存储。
5. `services/` 下的脚本不是一次性脚本，需要按服务方式托管运行。
